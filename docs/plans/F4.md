## Global Constraints

- Python `>=3.11,<3.14`; komutlar `C:\baykus\python` içinden: `uv run pytest -q`,
  `uv run ruff check . && uv run ruff format --check .`; satır 100. Düz `uv sync` train extra'yı siler →
  `uv sync --extra train`.
- Sürümler sabit: `onnxruntime==1.30.0`, `opencv-python==5.0.0.93`, `trackers==2.6.1`; C++ OpenCV 5.0.0 kaynaktan.
- `data/`, `runs/`, `mlruns/`, `demo-data/`, `models/`, `fixtures/f4/` (Release'ten açılan), `*.pt`, `*.onnx`,
  `*.engine` commit edilmez. `results/**/*.json`, `configs/**`, `fixtures/**` (yukarıdaki hariç) commit edilir.
- Görüntü I/O `baykus.io.imread_any` / `imwrite_any`; RGB BGR `uint8 (H, W, 3)`, IR gri `uint8 (H, W)`.
  Metin `encoding="utf-8"`.
- **Yarı çözünürlük gri** (ego ve donmuş kare): RGB → `cv2.cvtColor(BGR2GRAY)`; ikisi de
  `cv2.resize(g, (w // 2, h // 2), interpolation=cv2.INTER_AREA)` (sağlıktaki `_edges` ile aynı). Yarı
  çözünürlük piksel `i` ↔ tam `2i + 0,5`; `S = [[2,0,0.5],[0,2,0.5]]`, `A_full = S·A·S⁻¹`.
- Parametreler yalnız `configs/engine/motion.json`'dan (Görev 4 değerleri); kodda sabit yok. Ölçümden önce
  sabit: `K = 15`, `0,03 / 0,10`, ego eşikleri, nesil kuralları (bağlama ≤ 10 kare, IR'ye dönüş 5 kare),
  donmuş `diff_mad ≤ 0,5`, alarm 5'te 3, bölge kuralları (3 gözlem, ≤ 5 `yok`, 30 kare kayıp, 30 kare durdu),
  Kabul 1-9 eşikleri, demo ölçütü, iddia kuralı. Değişirse eski hâli silinmez, gerekçesiyle eklenir.
- Kare sayacı = **oturum içi istek sırası** (ekran kare atlamaz; Faz 3 kuralı). `t − K` bu sayaçla.
- GT: IR etiketleri, süzgeç flag 1, sınıf 1, görünürlük > 0,25 (`baykus.track.runner.GT_VIS`); kutu merkezi.
- Takipçi değişmez (`trackers==2.6.1`, `configs/engine/tracker.json`, `Tracker.FixtureParity` aynen).
- JSON'larda ölçülmemiş değer `null` (asla `NaN`); kanıtsız sayı yazılmaz. Her sonuç JSON'una `git_commit`,
  `created_at` (`baykus.runinfo`), girdi sha256'ları.
- Conventional Commits, atomik commit, Claude imzası yok. Token/şifre dosyaya yazılmaz.
- C++17, `clang-format` (Google, sütun 100), `-Wall -Wextra -Werror`; CI'da `BAYKUS_REQUIRE_FIXTURES=1`
  (kabul testleri atlanamaz). Kanıt komutları karar `fail` ise ≠ 0 döner (S6).
