# Baykuş — F4 (Faz 4) Uygulama Planı: Hareketli Hedef ve Operasyonel Ürün

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Motor kameranın kendi hareketini kestirip izleri harita koordinatına taşır, hareketli / duran diye işaretler, kesintiden sonra aynı haritada yeniden konumlanır; operatörün bölgelerini (alan, yasak, bekleme sınırı, sayım hattı) değerlendirip olay, alarm, araç özeti ve günlük üretir; ekran etkileşimli göreli haritayı, araç kartını, bölge editörünü, alarm panelini, zaman çizelgesini ve internetsiz dışa aktarmayı sunar; ayrım M3OT'ta döngüsel olmayan etiketler ve kör insan örneklemiyle ölçülür (S11).

**Architecture:** Önce Python: referans etiketleyici ve kör örneklem (KAPI), sonra ölçülen her şeyin Python referansı (`baykus.motion`: ego + nesil, harita belleği / yeniden konumlama, hareket, donmuş kare, oturumlu koşucu) ve ölçüm. Sonra C++ motoru aynı modüllerle, eşlikli; ardından yalnız C++'ta ve senaryo testli ürün mantığı (bölgeler, kurallar, alarmlar, günlük, araç özeti) ve yeni API uçları. Sonra ekran dört aşamada. Test dizileri dondurmadan sonra bir kez.

**Tech Stack:** Python 3.11 / 3.13, uv, numpy, `opencv-python==5.0.0.93` (SIFT, ORB, LK, `estimateAffinePartial2D`, `findHomography`), `onnxruntime==1.30.0`, `trackers==2.6.1` · C++17, OpenCV 5.0.0 kaynaktan (**+ `video`, `calib3d`, `features2d`, `flann`**), ORT 1.30.0, cpp-httplib, nlohmann/json, GoogleTest · Next.js 16 + TypeScript, Vitest · Docker Desktop, GitHub Actions.

**Spec:** `docs/design/faz4.md` **v3** (onaylı 2026-10-20: ürün paketleri A-D + harita belleği, kesme yok). Tasarımla çelişki olursa tasarım kazanır, plan güncellenir. Ayrıca `docs/design/faz3.md` (Faz 3 sözleşmeleri sürer, değişenler tasarım §5.8 "oturum kuralları"), `docs/spec.md` §2.3 S11.
