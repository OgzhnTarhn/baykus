> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sevk edilen E3c · ONNX FP32 ve Faz 2 sağlık dedektörü bir C++ motoruna (tespit, kalibre skor, sağlık + kare/zaman kuralı, ByteTrack) taşınır; Python referansıyla CI'da eşlikli; tek sayfa Next.js operatör ekranı ve `docker compose up` ile internetsiz çalışır (S7, S8).

**Architecture:** Önce Python tarafı: referans pipeline (`baykus.engine_ref`), kayma vektörü, `r_min` ve zaman kuralı (`baykus.health.guard`, `baykus.health.temporal`), takip referansı (`baykus.track`, `trackers==2.6.1`), ölçüm adaptörü ve fikstür üretici. Sonra C++ motoru (`engine/`, yalnız Docker'da derlenir) modül modül, her modül Python fikstürleriyle eşlikli; ortak yürütme yolu (`Runtime`) sunucu, bench ve CLI'ı besler. Sonra compose, Next.js UI (`ui/`), kapalı ağ kanıtları ve elle kabul. Son ölçümler (M3OT test) sistem dondurulduktan sonra bir kez.

**Tech Stack:** Python 3.11 / 3.13, uv, numpy, `opencv-python==5.0.0.93`, `onnxruntime==1.30.0`, `trackers==2.6.1`, pycocotools · C++17, GCC (Ubuntu 24.04), CMake, GoogleTest, Eigen3, nlohmann/json, cpp-httplib (tek başlık), OpenCV 5.0.0 (kaynaktan, `core imgproc imgcodecs`), ONNX Runtime 1.30.0 (hazır paket) · Next.js (App Router) + TypeScript + Tailwind + shadcn/ui, Vitest, Playwright (yalnız CI) · Docker Desktop (WSL2), docker compose, GitHub Actions.

**Spec:** `docs/design/faz3.md` v3 (onaylı tasarım; Kabul 1 sınır kuralları 2026-10-18 plan incelemesinde tasarıma işlendi), `docs/spec.md` §2.3 S7-S8, §7.4-7.5, §15-§18, §22; ADR 0007; `docs/health.md`; `docs/experiments.md` F3 girdileri. - Python `>=3.11,<3.14`; CI `uv sync --frozen`, extra'sız. Komutlar `C:\baykus\python` içinden:
  `uv run pytest -q`, `uv run ruff check . && uv run ruff format --check .`. Satır uzunluğu 100.
- Sürümler sabit: `onnxruntime==1.30.0`, `opencv-python==5.0.0.93`, `trackers==2.6.1` (pyproject'te `==`);
  C++'ta ORT `onnxruntime-linux-x64-1.30.0.tgz`, OpenCV **5.0.0 kaynaktan** (apt OpenCV kullanılmaz).
- `data/`, `runs/`, `mlruns/`, `demo-data/`, `models/`, `*.pt`, `*.onnx`, `*.engine` asla commit edilmez.
  `results/**/*.json`, `configs/**` ve `fixtures/**` commit edilir (fikstürler yalnız M3OT dev bölümü, CC BY 4.0).
- DroneVehicle görüntüsü repoya girmez (lisans, spec §7.6).
- Metin dosyaları `encoding="utf-8"`. Görüntü I/O `baykus.io.imread_any` / `imwrite_any`; RGB bellekte BGR
  `uint8 (H, W, 3)`, IR gri `uint8 (H, W)` (`IMREAD_GRAYSCALE`).
- Sınıf sırası `car, truck, bus, van, freight_car`; COCO `category_id = cls_id + 1`; pycocotools
  `maxDets` ≥ 1000 (`baykus.eval.coco_eval.MAX_DETS`). M3OT sınıfsız: bütün tahminler kategori 1.

- Geliştirme bölümü tek kayıtta: `configs/m3ot_dev.json` = `{"split": "val"|"train", "sequences": [...],

- Seçimler yalnız train (`r_min`) ya da M3OT geliştirme bölümü (demo dizisi, fikstür); M3OT test yalnız Görev 36.
- Ölçümden önce sabit değerler (tasarım): kare kuralı ölçütü (train temiz alarm × 50 ≤ kare sayısı); zaman
