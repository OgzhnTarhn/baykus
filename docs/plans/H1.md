# Baykuş — H1 (1. hafta) Uygulama Planı: Temel, Doğrulama, Veri ve Ölçüm

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repo iskeletini ve araçlarını kurmak, kritik belirsizlikleri spike'larla çözmek, DroneVehicle'ı temiz bir YOLO/COCO veri setine çevirmek ve testli bir değerlendirme modülü yazmak.

**Architecture:** Bütün Python kodu `python/` altındaki `baykus` paketinde, `uv` ile yönetiliyor. Veri hattı küçük ve saf fonksiyonlardan oluşuyor: geometri, ayrıştırma, doğrulama, dönüştürme, aydınlatma, 4 kanal, COCO, rapor. Bunlar tek bir `baykus-data` CLI'ında alt komut olarak birleşiyor. Değerlendirme pycocotools üzerine ince bir katman.

**Tech Stack:** Python 3.11, uv 0.11, numpy, opencv-python, tifffile, pycocotools, pyyaml, matplotlib, pytest, ruff, pre-commit; spike için ultralytics (YOLO26), onnx, onnxruntime; GitHub Actions; Google Colab.

**Spec:** `docs/spec.md` (v3.0). Bu plan spec'in §22 H1 bölümünü (issue #1-#12) uygular. Spec ile çelişki olursa spec kazanır, plan güncellenir.

## Global Constraints

- Python `>=3.11,<3.13`. Paket adı `baykus`, CLI adları `baykus-*`. Python komutları `C:\baykus\python` içinden `uv run ...` ile çalışır.
- Repo yolu ASCII: `C:\baykus`. Veri `C:\baykus\data\` altında durur ve **asla commit edilmez.** Ağırlıklar (`*.pt`, `*.onnx`, `*.engine`) da edilmez.
- Satır sonları LF (`.gitattributes`: `* text=auto eol=lf`). Windows'taki global `core.autocrlf=true` buna göre geçersiz kılınır.
- Bütün metin dosyaları `encoding="utf-8"` ile okunur ve yazılır. Görüntü okuma `imread_any()` (np.fromfile + cv2.imdecode) ile yapılır, `cv2.imread` kullanılmaz.
- Kutu tipi **yatay kutu (HBB)**, piksel cinsinden `x1, y1, x2, y2`. YOLO etiketi `cls cx cy w h` (0-1 arası).
- Sınıf sırası sabit: `0 car, 1 truck, 2 bus, 3 van, 4 freight_car`. COCO `category_id = cls_id + 1`.
- DroneVehicle görüntüleri 840×712. 100 px kenarlık kırpılır → **640×512**.
- Değerlendirmede `maxDets` en az **1000** (görüntü başına yüzlerce araç olabilir).
- Test seti sadece final ölçümde kullanılır. H1'de test seti üzerinde metrik hesaplanmaz, sadece veri istatistiği çıkarılır.
- Hiçbir token veya şifre dosyaya ya da repoya yazılmaz. Kaggle token'ı sadece ortam değişkeni veya Colab Secrets'ta durur.
- Conventional Commits, atomik commit'ler (her commit tek mantıksal değişiklik). Commit mesajlarında Claude imzası (`Co-Authored-By` vb.) yok.
- Lisans AGPL-3.0.

## Review Focus

Spec'in açıkça söylemediği ama gerçek veride kesin karşılaşacağımız durumlar. Her birinin testi ilgili göreve eklendi:

1. **Kısmen ya da tamamen 100 px kenarlıkta kalan nesneler** → kısmen kalanın kutusu kırpılır, tamamen kalan atılır, sıfır alanlı kutu üretilmez. (Görev 7 ve Görev 10 testleri)
2. **Bir görüntüde 100'den fazla araç (otoparklar)** → pycocotools'un varsayılan `maxDets=100` sınırı skoru sessizce düşürmemeli. (Görev 14 testi: 150 nesneli görüntü)
3. **Yazım hatalı veya bilinmeyen sınıf adları** (ör. `feright car`, `truvk`) → bilinen varyantlar normalize edilir, bilinmeyenler sessizce atılmaz, raporlanır. (Görev 8 testi)
4. **Eşi olmayan veya okunamayan RGB/IR dosyaları, boyutları farklı çiftler** → dışlanır ve nedeniyle raporlanır. Hattı çökertmez. (Görev 9 testi)
5. **Hiç nesne içermeyen görüntüler ve boş tahmin listeleri** → boş etiket dosyası yazılır (arka plan görüntüsü), değerlendirme sıfır döner, hata vermez. (Görev 10 ve Görev 14 testleri)

```python
"""Spike A: Ultralytics YOLO26 + 4 kanallı TIFF uçtan uca çalışıyor mu? (CPU, sentetik veri)

Çalıştırma (python/ içinden):  uv run python ../scripts/spikes/ultralytics_4ch.py
Çıktı: data/spikes/u4ch/result_<layout>.json
"""

from __future__ import annotations

import json
import traceback
from pathlib import Path

import numpy as np
import tifffile

ROOT = Path(__file__).resolve().parents[2]
OUT = ROOT / "data" / "spikes" / "u4ch"
SIZE = 128


def write_tif(path: Path, img: np.ndarray, layout: str) -> None:
    """img HWC, kanallar R,G,B,T sırasıyla."""
    if layout == "hwc":
        tifffile.imwrite(path, img, planarconfig="contig", compression="deflate")
    else:
        tifffile.imwrite(
            path, np.transpose(img, (2, 0, 1)), planarconfig="separate", compression="deflate"
        )


def make_dataset(root: Path, layout: str, n_train: int = 16, n_val: int = 4) -> Path:
    rng = np.random.default_rng(0)
    for split, n in (("train", n_train), ("val", n_val)):
        (root / "images" / split).mkdir(parents=True, exist_ok=True)
        (root / "labels" / split).mkdir(parents=True, exist_ok=True)
        for i in range(n):
            img = rng.integers(0, 40, (SIZE, SIZE, 4), dtype=np.uint8)
            x1, y1 = (int(v) for v in rng.integers(10, SIZE - 50, 2))
            w, h = (int(v) for v in rng.integers(15, 40, 2))
            img[y1 : y1 + h, x1 : x1 + w, :3] = 200  # RGB'de parlak kutu
            img[y1 : y1 + h, x1 : x1 + w, 3] = 255  # termalde sıcak kutu
            write_tif(root / "images" / split / f"{i:04d}.tif", img, layout)
            cx, cy = (x1 + w / 2) / SIZE, (y1 + h / 2) / SIZE
            (root / "labels" / split / f"{i:04d}.txt").write_text(
                f"0 {cx:.6f} {cy:.6f} {w / SIZE:.6f} {h / SIZE:.6f}\n", encoding="utf-8"
            )
    yaml_path = root / "data.yaml"
    yaml_path.write_text(
        f"path: {root.as_posix()}\ntrain: images/train\nval: images/val\n"
        "channels: 4\nnames:\n  0: car\n",
        encoding="utf-8",
    )
    return yaml_path


def probe_channel_order(root: Path, layout: str) -> dict:
    """Modelin gerçekte gördüğü kanal sırası (okuma + LetterBox + Format, augment yok)."""
    from ultralytics.data.dataset import YOLODataset

    d = root / "probe"
    (d / "images").mkdir(parents=True, exist_ok=True)
    (d / "labels").mkdir(parents=True, exist_ok=True)
    img = np.zeros((SIZE, SIZE, 4), np.uint8)
    for c, v in enumerate((10, 20, 30, 40)):  # R=10, G=20, B=30, T=40
        img[..., c] = v
    write_tif(d / "images" / "probe.tif", img, layout)
    (d / "labels" / "probe.txt").write_text("0 0.5 0.5 0.2 0.2\n", encoding="utf-8")
    ds = YOLODataset(
        img_path=str(d / "images"), data={"names": {0: "car"}, "channels": 4},
        task="detect", imgsz=SIZE, augment=False,
    )
    t = ds[0]["img"]  # CHW, modele giden sıra
    seen = [int(t[c, SIZE // 2, SIZE // 2]) for c in range(t.shape[0])]
    # [10, 20, 30, 40] → RGBT yazmak doğru; [30, 20, 10, 40] → model BGRT görüyor
    return {"model_sees_values": seen}


def probe_first_conv_init() -> dict:
    """Eğitimsiz: COCO ağırlıkları 4 kanallı ilk katmana nasıl aktarılıyor?"""
    from ultralytics import YOLO
    from ultralytics.nn.tasks import DetectionModel

    src = YOLO("yolo26n.pt").model
    w3 = src.model[0].conv.weight.detach().float().clone()  # (out, 3, k, k)
    m4 = DetectionModel("yolo26n.yaml", ch=4, nc=1, verbose=False)
    m4.load(src, verbose=True)
    w4 = m4.model[0].conv.weight.detach().float()  # (out, 4, k, k)
    return {
        "w3_shape": list(w3.shape),
        "w4_shape": list(w4.shape),
        "ch0_2_equal_coco": bool(torch_allclose(w4[:, :3], w3)),
        "ch3_equals_rgb_mean": bool(torch_allclose(w4[:, 3], w3.mean(1))),
        "ch3_std": float(w4[:, 3].std()),
        "coco_std": float(w3.std()),
    }


def torch_allclose(a, b) -> bool:
    import torch

    return torch.allclose(a, b, atol=1e-6)


def set_rgb_mean(trainer) -> None:
    """Callback: ilk katmanın 4. kanalını RGB ağırlıklarının ortalamasıyla başlat (model + EMA)."""
    import torch

    with torch.no_grad():
        for m in (trainer.model, trainer.ema.ema if trainer.ema else None):
            if m is None:
                continue
            w = m.model[0].conv.weight
            w[:, 3] = w[:, :3].mean(1)
    trainer.rgb_mean_applied = True


def run(layout: str) -> dict:
    import cv2
    import ultralytics
    from ultralytics import YOLO

    res: dict = {"layout": layout, "ultralytics": ultralytics.__version__}
    root = OUT / layout
    yaml_path = make_dataset(root, layout)
    sample = root / "images" / "train" / "0000.tif"
    original = tifffile.imread(sample)
    res["tifffile_shape"] = list(original.shape)

    try:
        from ultralytics.utils.patches import imread

        arr = imread(str(sample), cv2.IMREAD_UNCHANGED)
        res["ultralytics_imread_shape"] = None if arr is None else list(arr.shape)
        if arr is not None and arr.ndim == 3 and arr.shape[2] == 4:
            ref = original if layout == "hwc" else np.transpose(original, (1, 2, 0))
            res["channel_order_matches_RGBT"] = bool((arr == ref).all())
            res["channel_order_matches_BGRT"] = bool((arr[..., [2, 1, 0, 3]] == ref).all())
    except Exception:
        res["imread_error"] = traceback.format_exc(limit=3)

    for key, fn in (
        ("channel_probe", lambda: probe_channel_order(root, layout)),
        ("first_conv_init", probe_first_conv_init),
    ):
        try:
            res[key] = fn()
        except Exception:
            res[f"{key}_error"] = traceback.format_exc(limit=5)

    stages = {}
    try:
        model = YOLO("yolo26n.pt")
        model.train(
            data=str(yaml_path), epochs=1, imgsz=SIZE, batch=4, device="cpu", workers=0,
            plots=False, project=str(OUT / "runs"), name=layout, exist_ok=True, verbose=False,
        )
        stages["train"] = "ok"
        res["first_conv_weight_shape"] = list(model.model.model[0].conv.weight.shape)
        metrics = model.val(data=str(yaml_path), imgsz=SIZE, batch=4, device="cpu", plots=False)
        stages["val"] = "ok"
        res["val_map50"] = float(metrics.box.map50)
        onnx_path = model.export(format="onnx", imgsz=SIZE)
        stages["export"] = "ok"
        import onnx
        import onnxruntime as ort

        m = onnx.load(onnx_path)
        dims = lambda v: [d.dim_value or d.dim_param for d in v.type.tensor_type.shape.dim]  # noqa: E731
        res["onnx_inputs"] = [{v.name: dims(v)} for v in m.graph.input]
        res["onnx_outputs"] = [{v.name: dims(v)} for v in m.graph.output]
        sess = ort.InferenceSession(onnx_path, providers=["CPUExecutionProvider"])
        name = sess.get_inputs()[0].name
        outs = sess.run(None, {name: np.zeros((1, 4, SIZE, SIZE), np.float32)})
        res["onnxruntime_output_shapes"] = [list(o.shape) for o in outs]
        stages["onnxruntime"] = "ok"
    except Exception:
        res["pipeline_error"] = traceback.format_exc(limit=5)

    # rgb_mean başlatması callback ile (Ultralytics'e yama yok)
    try:
        m = YOLO("yolo26n.pt")
        m.add_callback("on_pretrain_routine_end", set_rgb_mean)
        m.train(
            data=str(yaml_path), epochs=1, imgsz=SIZE, batch=4, device="cpu", workers=0,
            plots=False, project=str(OUT / "runs"), name=f"{layout}_rgbmean", exist_ok=True,
            verbose=False,
        )
        res["rgb_mean_callback_applied"] = bool(getattr(m.trainer, "rgb_mean_applied", False))
        stages["train_rgb_mean"] = "ok"
    except Exception:
        res["rgb_mean_error"] = traceback.format_exc(limit=5)
    res["stages"] = stages
    return res


def main() -> None:
    OUT.mkdir(parents=True, exist_ok=True)
    for layout in ("hwc", "chw"):
        res = run(layout)
        (OUT / f"result_{layout}.json").write_text(json.dumps(res, indent=2), encoding="utf-8")
        print(json.dumps(res, indent=2))


if __name__ == "__main__":
    main()
```

"""Spike B: DroneVehicle Kaggle kopyasının gerçek yapısını çıkarır.

Çalıştırma (python/ içinden):
  uv run python ../scripts/spikes/inspect_dronevehicle.py ../data/raw/dronevehicle ../data/spikes/dv_inspect.json
"""

from __future__ import annotations

import collections
import json
import random
import sys
import xml.etree.ElementTree as ET
from pathlib import Path

import cv2
import numpy as np

IMG_EXT = {".jpg", ".jpeg", ".png", ".bmp", ".tif", ".tiff"}


def main(root: Path, out: Path, n_sample: int = 400) -> None:
    rep: dict = {}
    files = [p for p in root.rglob("*") if p.is_file()]
    tree = collections.Counter((str(p.parent.relative_to(root)), p.suffix.lower()) for p in files)
    rep["files"] = [{"dir": d, "ext": e, "count": c} for (d, e), c in sorted(tree.items())]

    xmls = sorted(p for p in files if p.suffix.lower() == ".xml")
    rep["n_xml"] = len(xmls)
    rep["xml_samples"] = [
        {"path": str(p.relative_to(root)), "head": p.read_text("utf-8", errors="replace")[:1500]}
        for p in xmls[:2]
    ]
    names, tags, bad = collections.Counter(), collections.Counter(), []
    max_objs = 0
    for p in xmls:
        try:
            r = ET.parse(p).getroot()
        except ET.ParseError:
            bad.append(str(p.relative_to(root)))
            continue
        objs = list(r.iter("object"))
        max_objs = max(max_objs, len(objs))
        for o in objs:
            names[(o.findtext("name") or "").strip()] += 1
            for c in o:
                if c.tag not in {"name", "pose", "truncated", "difficult"}:
                    tags[c.tag] += 1
    rep.update(class_names=dict(names), shape_tags=dict(tags), n_bad_xml=len(bad),
               bad_xml=bad[:50], max_objects_per_file=max_objs)

    imgs = [p for p in files if p.suffix.lower() in IMG_EXT]
    random.seed(0)
    stats = collections.Counter()
    for p in random.sample(imgs, min(n_sample, len(imgs))):
        a = cv2.imdecode(np.fromfile(p, np.uint8), cv2.IMREAD_UNCHANGED)
        d = str(p.parent.relative_to(root))
        if a is None:
            stats[(d, "UNREADABLE")] += 1
            continue
        ch = 1 if a.ndim == 2 else a.shape[2]
        gray3 = ch == 3 and bool((a[..., 0] == a[..., 1]).all() and (a[..., 1] == a[..., 2]).all())
        stats[(d, f"{a.shape[1]}x{a.shape[0]}x{ch}{' gray3' if gray3 else ''}")] += 1
    rep["image_sample_stats"] = [{"dir": d, "kind": k, "count": c} for (d, k), c in sorted(stats.items())]
    rep["other_files"] = [
        str(p.relative_to(root)) for p in files
        if p.suffix.lower() in {".txt", ".csv", ".json", ".md", ".xlsx"}
    ][:100]
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(json.dumps(rep, indent=2, ensure_ascii=False), encoding="utf-8")
    print(json.dumps({k: v for k, v in rep.items() if k != "xml_samples"}, indent=2, ensure_ascii=False))


if __name__ == "__main__":
    main(Path(sys.argv[1]), Path(sys.argv[2]))
```

"""Kutu geometrisi: poligon → yatay kutu, kırpma/kaydırma, YOLO normalizasyonu."""

from __future__ import annotations

import numpy as np

Box = tuple[float, float, float, float]


def polygon_to_hbb(points: np.ndarray) -> Box:
    pts = np.asarray(points, dtype=np.float64).reshape(-1, 2)
    if pts.shape[0] < 2:
        raise ValueError("polygon_to_hbb en az 2 nokta ister")
    x1, y1 = pts.min(axis=0)
    x2, y2 = pts.max(axis=0)
    return float(x1), float(y1), float(x2), float(y2)


def shift_and_clip(
    box: Box, dx: float, dy: float, width: int, height: int, min_size: float = 1.0
) -> Box | None:
    x1, y1, x2, y2 = box
    x1, x2 = x1 - dx, x2 - dx
    y1, y2 = y1 - dy, y2 - dy
    x1, x2 = min(max(x1, 0.0), width), min(max(x2, 0.0), width)
    y1, y2 = min(max(y1, 0.0), height), min(max(y2, 0.0), height)
    if x2 - x1 < min_size or y2 - y1 < min_size:
        return None
    return float(x1), float(y1), float(x2), float(y2)


def xyxy_to_yolo(box: Box, width: int, height: int) -> tuple[float, float, float, float]:
    x1, y1, x2, y2 = box
    return (
        (x1 + x2) / 2 / width,
        (y1 + y2) / 2 / height,
        (x2 - x1) / width,
        (y2 - y1) / height,
    )
```

"""Sabit sınıf listesi ve DroneVehicle ham ad varyantları."""

from __future__ import annotations

CLASS_NAMES: tuple[str, ...] = ("car", "truck", "bus", "van", "freight_car")

# Spike B'de görülen gerçek varyantlarla güncellenir.
CLASS_ALIASES: dict[str, str] = {
    "car": "car",
    "truck": "truck",
    "truvk": "truck",
    "bus": "bus",
    "van": "van",
    "freight car": "freight_car",
    "freight_car": "freight_car",
    "feright car": "freight_car",
    "feright_car": "freight_car",
    "feright": "freight_car",
}


def normalize_class(raw: str) -> str | None:
    return CLASS_ALIASES.get(" ".join(raw.strip().lower().split()))


def class_id(name: str) -> int:
    return CLASS_NAMES.index(name)


def coco_category_id(cls_id: int) -> int:
    return cls_id + 1

"""Windows'ta ASCII dışı yollarda da çalışan görüntü okuma/yazma."""

from __future__ import annotations

from pathlib import Path

import cv2
import numpy as np


def imread_any(path: Path, flags: int = cv2.IMREAD_UNCHANGED) -> np.ndarray | None:
    try:
        buf = np.fromfile(str(path), dtype=np.uint8)
    except (FileNotFoundError, OSError):
        return None
    if buf.size == 0:
        return None
    return cv2.imdecode(buf, flags)


def imwrite_any(path: Path, img: np.ndarray, params: list[int] | None = None) -> None:
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    ok, enc = cv2.imencode(path.suffix, img, params or [])
    if not ok:
        raise OSError(f"görüntü kodlanamadı: {path}")
    enc.tofile(str(path))
```

"""DroneVehicle VOC-benzeri XML etiket ayrıştırıcı (polygon ve bndbox)."""

from __future__ import annotations

import xml.etree.ElementTree as ET
from dataclasses import dataclass, field
from pathlib import Path

import numpy as np

from baykus.classes import normalize_class


@dataclass(frozen=True)
class RawObject:
    cls_name: str
    points: np.ndarray  # (N, 2), orijinal görüntü koordinatları


@dataclass
class ParseResult:
    objects: list[RawObject] = field(default_factory=list)
    unknown_classes: list[str] = field(default_factory=list)
    skipped_shapes: int = 0


def _points(obj: ET.Element) -> np.ndarray | None:
    poly = obj.find("polygon")
    if poly is not None:
        xs = [float(poly.findtext(f"x{i}")) for i in range(1, 5)]
        ys = [float(poly.findtext(f"y{i}")) for i in range(1, 5)]
        return np.stack([xs, ys], axis=1)
    bb = obj.find("bndbox")
    if bb is not None:
        x1, y1 = float(bb.findtext("xmin")), float(bb.findtext("ymin"))
        x2, y2 = float(bb.findtext("xmax")), float(bb.findtext("ymax"))
        return np.array([[x1, y1], [x2, y1], [x2, y2], [x1, y2]])
    return None


def parse_annotation(path: Path) -> ParseResult:
    root = ET.parse(path).getroot()
    res = ParseResult()
    for obj in root.iter("object"):
        raw = obj.findtext("name") or ""
        name = normalize_class(raw)
        if name is None:
            res.unknown_classes.append(raw.strip())
            continue
        pts = _points(obj)
        if pts is None:
            res.skipped_shapes += 1
            continue
        res.objects.append(RawObject(name, pts))
    return res

"""RGB/IR çiftlerinin ve etiketlerin bütünlük kontrolü (FR-D1)."""

from __future__ import annotations

import collections
import json
import xml.etree.ElementTree as ET
from dataclasses import asdict, dataclass
from pathlib import Path

from baykus.data.dronevehicle import parse_annotation
from baykus.data.layout import IMG_EXTS, RAW_SIZE, SplitDirs, find_image
from baykus.io import imread_any


@dataclass(frozen=True)
class Issue:
    split: str
    stem: str
    reason: str


def _stems(dirs: SplitDirs) -> list[str]:
    stems: set[str] = set()
    for folder in (dirs.rgb, dirs.ir):
        if folder.exists():
            stems |= {p.stem for p in folder.iterdir() if p.suffix.lower() in IMG_EXTS}
    for folder in (dirs.label_rgb, dirs.label_ir):
        if folder.exists():
            stems |= {p.stem for p in folder.glob("*.xml")}
    return sorted(stems)


def _check(dirs: SplitDirs, stem: str) -> str | None:
    rgb_p, ir_p = find_image(dirs.rgb, stem), find_image(dirs.ir, stem)
    if rgb_p is None:
        return "missing_rgb"
    if ir_p is None:
        return "missing_ir"
    lr, li = dirs.label_rgb / f"{stem}.xml", dirs.label_ir / f"{stem}.xml"
    if not lr.exists():
        return "missing_label_rgb"
    if not li.exists():
        return "missing_label_ir"
    rgb, ir = imread_any(rgb_p), imread_any(ir_p)
    if rgb is None:
        return "unreadable_rgb"
    if ir is None:
        return "unreadable_ir"
    if rgb.shape[:2] != ir.shape[:2]:
        return "size_mismatch"
    if (rgb.shape[1], rgb.shape[0]) != RAW_SIZE:
        return "unexpected_size"
    for path, reason in ((lr, "bad_xml_rgb"), (li, "bad_xml_ir")):
        try:
            parse_annotation(path)
        except ET.ParseError:
            return reason
    return None


def verify_split(dirs: SplitDirs, split: str) -> tuple[list[str], list[Issue]]:
    ok, issues = [], []
    for stem in _stems(dirs):
        reason = _check(dirs, stem)
        if reason is None:
            ok.append(stem)
        else:
            issues.append(Issue(split, stem, reason))
    return ok, issues


def write_outputs(meta_dir: Path, ok: dict[str, list[str]], issues: list[Issue]) -> None:
    meta_dir.mkdir(parents=True, exist_ok=True)
    (meta_dir / "excluded.txt").write_text(
        "".join(f"{i.split}/{i.stem}\t{i.reason}\n" for i in issues), encoding="utf-8"
    )
    (meta_dir / "ok_stems.json").write_text(json.dumps(ok, indent=1), encoding="utf-8")
    report = {
        "ok_counts": {k: len(v) for k, v in ok.items()},
        "issues_by_reason": dict(collections.Counter(i.reason for i in issues)),
        "issues": [asdict(i) for i in issues[:200]],
    }
    (meta_dir / "verify_report.json").write_text(json.dumps(report, indent=2), encoding="utf-8")

"""Kenarlık kırpma + OBB→HBB→YOLO etiket dönüşümü (FR-D2, FR-D3)."""

from __future__ import annotations

import shutil
from pathlib import Path

import cv2
import numpy as np
from tqdm import tqdm

from baykus.classes import class_id
from baykus.data.dronevehicle import parse_annotation
from baykus.data.geometry import polygon_to_hbb, shift_and_clip, xyxy_to_yolo
from baykus.data.layout import CROP, OUT_SIZE, SPLITS, SplitDirs, find_image
from baykus.io import imread_any, imwrite_any

W, H = OUT_SIZE


def to_single_channel(img: np.ndarray) -> np.ndarray:
    if img.ndim == 2:
        return img
    if img.shape[2] == 3 and (img[..., 0] == img[..., 1]).all() and (img[..., 1] == img[..., 2]).all():
        return img[..., 0].copy()
    return cv2.cvtColor(img[..., :3], cv2.COLOR_BGR2GRAY)


def _crop(img: np.ndarray) -> np.ndarray:
    return img[CROP : CROP + H, CROP : CROP + W]


def convert_labels(xml_path: Path) -> tuple[list[str], dict]:
    res = parse_annotation(xml_path)
    lines: list[str] = []
    dropped = 0
    for obj in res.objects:
        box = shift_and_clip(polygon_to_hbb(obj.points), CROP, CROP, W, H)
        if box is None:
            dropped += 1
            continue
        cx, cy, bw, bh = xyxy_to_yolo(box, W, H)
        lines.append(f"{class_id(obj.cls_name)} {cx:.6f} {cy:.6f} {bw:.6f} {bh:.6f}")
    stats = {"kept": len(lines), "dropped": dropped,
             "unknown": len(res.unknown_classes), "skipped": res.skipped_shapes}
    return lines, stats


def convert_split(dirs: SplitDirs, split: str, stems: list[str], out_root: Path) -> dict:
    total = {f"{s}_{k}": 0 for s in ("ir", "rgb") for k in ("kept", "dropped", "unknown", "skipped")}
    for stem in tqdm(stems, desc=f"convert {split}", leave=False):
        rgb = imread_any(find_image(dirs.rgb, stem), cv2.IMREAD_COLOR)
        ir = imread_any(find_image(dirs.ir, stem), cv2.IMREAD_UNCHANGED)
        imwrite_any(out_root / "rgb/images" / split / f"{stem}.jpg", _crop(rgb),
                    [cv2.IMWRITE_JPEG_QUALITY, 95])
        imwrite_any(out_root / "ir/images" / split / f"{stem}.png", _crop(to_single_channel(ir)))
        for label_set, folder in (("ir", dirs.label_ir), ("rgb", dirs.label_rgb)):
            lines, st = convert_labels(folder / f"{stem}.xml")
            dst = out_root / f"labels_{label_set}" / split / f"{stem}.txt"
            dst.parent.mkdir(parents=True, exist_ok=True)
            dst.write_text("".join(f"{ln}\n" for ln in lines), encoding="utf-8")
            for k, v in st.items():
                total[f"{label_set}_{k}"] += v
    total["images"] = len(stems)
    return total


def activate_label_set(out_root: Path, modality: str, label_set: str) -> int:
    n = 0
    for split in SPLITS:
        src = out_root / f"labels_{label_set}" / split
        dst = out_root / modality / "labels" / split
        if dst.exists():
            shutil.rmtree(dst)
        dst.mkdir(parents=True, exist_ok=True)
        if not src.exists():
            continue
        for f in src.glob("*.txt"):
            shutil.copy2(f, dst / f.name)
            n += 1
    return n
```

"""Aydınlatma etiketi: RGB parlaklığından, resmi dağılıma uydurulmuş eşiklerle (FR-D4).

Varsayım (ADR 0005): DroneVehicle'ın Gündüz/Gece/Karanlık gece ayrımı RGB parlaklığıyla
monoton ilişkili. Doğrulama: her seviyeden örnek mozaik + kullanıcının gözle kontrolü.
"""

from __future__ import annotations

import cv2
import numpy as np

LEVELS = ("dark_night", "night", "day")
OFFICIAL_COUNTS = {"day": 14478, "night": 5468, "dark_night": 8493}


def mean_brightness(bgr: np.ndarray) -> float:
    hsv = cv2.cvtColor(bgr, cv2.COLOR_BGR2HSV)
    return float(hsv[..., 2].mean())


def fit_thresholds(values: np.ndarray, counts: dict[str, int]) -> tuple[float, float]:
    v = np.sort(np.asarray(values, dtype=float))
    total = sum(counts.values())
    n_dark = round(len(v) * counts["dark_night"] / total)
    n_night = round(len(v) * counts["night"] / total)
    def cut(k: int) -> float:
        if k <= 0:
            return float(v[0])
        if k >= len(v):
            return float(v[-1]) + 1.0
        return float((v[k - 1] + v[k]) / 2)
    return cut(n_dark), cut(n_dark + n_night)


def assign(values: np.ndarray, thresholds: tuple[float, float]) -> list[str]:
    t_dark, t_night = thresholds
    return ["dark_night" if x < t_dark else "night" if x < t_night else "day" for x in values]
```

"""RGB + termal → 4 kanallı TIFF (FR-D5). Biçim ADR 0004'te."""

from __future__ import annotations

from pathlib import Path

import numpy as np
import tifffile

TIFF_LAYOUT = "pages"  # ADR 0004: her kanal ayrı gri sayfa (Spike A)


def stack_rgbt(bgr: np.ndarray, ir: np.ndarray) -> np.ndarray:
    if bgr.shape[:2] != ir.shape[:2]:
        raise ValueError(f"boyut uyuşmazlığı: {bgr.shape[:2]} vs {ir.shape[:2]}")
    ir2 = ir if ir.ndim == 2 else ir[..., 0]
    return np.dstack([bgr[..., 2], bgr[..., 1], bgr[..., 0], ir2]).astype(np.uint8)


def write_rgbt4(path: Path, rgbt: np.ndarray) -> None:
    """Her kanal ayrı gri sayfa. Tek sayfalı RGB+alfa TIFF'te OpenCV, RGB'yi 4. kanalla
    çarpıp BGR'ye çeviriyor (Spike A); çok sayfalıyı Ultralytics sırayla yığıyor."""
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    with tifffile.TiffWriter(path) as tw:
        for c in range(rgbt.shape[2]):
            tw.write(rgbt[..., c], photometric="minisblack", compression="deflate")
```

"""YOLO etiketleri → COCO JSON + kırılım listeleri (FR-D6)."""

from __future__ import annotations

import csv
from pathlib import Path

from baykus.classes import CLASS_NAMES, coco_category_id


def yolo_to_coco(label_dir: Path, stems: list[str], width: int, height: int) -> dict:
    images, anns = [], []
    for img_id, stem in enumerate(sorted(stems), start=1):
        images.append({"id": img_id, "file_name": stem, "width": width, "height": height})
        f = Path(label_dir) / f"{stem}.txt"
        text = f.read_text(encoding="utf-8") if f.exists() else ""
        for line in text.splitlines():
            if not line.strip():
                continue
            c, cx, cy, w, h = line.split()
            bw, bh = float(w) * width, float(h) * height
            x, y = float(cx) * width - bw / 2, float(cy) * height - bh / 2
            anns.append({
                "id": len(anns) + 1, "image_id": img_id,
                "category_id": coco_category_id(int(c)),
                "bbox": [round(x, 4), round(y, 4), round(bw, 4), round(bh, 4)],
                "area": bw * bh, "iscrowd": 0,
            })
    cats = [{"id": coco_category_id(i), "name": n} for i, n in enumerate(CLASS_NAMES)]
    return {"images": images, "annotations": anns, "categories": cats}


def illumination_slices(csv_path: Path, split: str, stem_to_id: dict[str, int]) -> dict[str, list[int]]:
    out: dict[str, list[int]] = {"day": [], "night": [], "dark_night": []}
    with Path(csv_path).open(encoding="utf-8") as f:
        for row in csv.DictReader(f):
            if row["split"] == split and row["stem"] in stem_to_id:
                out[row["illumination"]].append(stem_to_id[row["stem"]])
    for v in out.values():
        v.sort()
    return out
```

"""Yatay kutular için IoU (xyxy)."""

from __future__ import annotations

import numpy as np


def box_iou(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    a = np.asarray(a, dtype=np.float64).reshape(-1, 4)
    b = np.asarray(b, dtype=np.float64).reshape(-1, 4)
    ix1 = np.maximum(a[:, None, 0], b[None, :, 0])
    iy1 = np.maximum(a[:, None, 1], b[None, :, 1])
    ix2 = np.minimum(a[:, None, 2], b[None, :, 2])
    iy2 = np.minimum(a[:, None, 3], b[None, :, 3])
    inter = np.clip(ix2 - ix1, 0, None) * np.clip(iy2 - iy1, 0, None)
    area_a = (a[:, 2] - a[:, 0]) * (a[:, 3] - a[:, 1])
    area_b = (b[:, 2] - b[:, 0]) * (b[:, 3] - b[:, 1])
    union = area_a[:, None] + area_b[None, :] - inter
    return np.where(union > 0, inter / np.where(union > 0, union, 1), 0.0)

"""pycocotools üzerine ince katman: mAP50, mAP50-95, sınıf ve boyut kırılımları, kırılımlı ölçüm.

Not: maxDets=1000 — DroneVehicle'da görüntü başına 100'den fazla araç olabilir.
"""

from __future__ import annotations

import contextlib
import io

import numpy as np
from pycocotools.coco import COCO
from pycocotools.cocoeval import COCOeval

MAX_DETS = 1000
_SIZES = {"small": 1, "medium": 2, "large": 3}  # COCOeval areaRng indeksleri


def _ap(prec: np.ndarray) -> float | None:
    valid = prec[prec > -1]
    return float(valid.mean()) if valid.size else None


def _empty(gt: COCO, n_images: int) -> dict:
    names = [c["name"] for c in gt.loadCats(gt.getCatIds())]
    return {"map50": 0.0, "map50_95": 0.0, "per_class": {n: 0.0 for n in names},
            "per_size": {k: 0.0 for k in _SIZES}, "n_images": n_images, "n_dets": 0}


def evaluate_coco(gt: COCO, dets: list[dict], img_ids: list[int] | None = None) -> dict:
    ids = sorted(img_ids) if img_ids is not None else sorted(gt.getImgIds())
    id_set = set(ids)
    dets = [d for d in dets if d["image_id"] in id_set]
    if not dets or not ids:
        return _empty(gt, len(ids))
    with contextlib.redirect_stdout(io.StringIO()):
        dt = gt.loadRes(dets)
        ev = COCOeval(gt, dt, iouType="bbox")
        ev.params.imgIds = ids
        ev.params.maxDets = [1, 10, MAX_DETS]
        ev.evaluate()
        ev.accumulate()
    p = ev.eval["precision"]  # [T, R, K, A, M]
    m = len(ev.params.maxDets) - 1
    cats = gt.loadCats(ev.params.catIds)
    return {
        "map50": _ap(p[0, :, :, 0, m]) or 0.0,
        "map50_95": _ap(p[:, :, :, 0, m]) or 0.0,
        "per_class": {c["name"]: _ap(p[0, :, k, 0, m]) for k, c in enumerate(cats)},
        "per_size": {s: _ap(p[0, :, :, a, m]) for s, a in _SIZES.items()},
        "n_images": len(ids),
        "n_dets": len(dets),
    }


def evaluate_slices(gt: COCO, dets: list[dict], slices: dict[str, list[int]]) -> dict[str, dict]:
    return {name: evaluate_coco(gt, dets, ids) for name, ids in slices.items()}
```

import collections
import csv
import json

from pathlib import Path

import numpy as np

matplotlib.use("Agg")

def _centers(coco: dict) -> dict[str, list[tuple[int, float, float]]]:
    names = {im["id"]: im["file_name"] for im in coco["images"]}
    out: dict[str, list[tuple[int, float, float]]] = collections.defaultdict(list)
    for a in coco["annotations"]:
        x, y, w, h = a["bbox"]
        out[names[a["image_id"]]].append((a["category_id"], x + w / 2, y + h / 2))
    return out


def label_shift(coco_ir: dict, coco_rgb: dict, max_dist: float = 40.0) -> dict:
    """Aynı nesnenin IR ve RGB etiketlerindeki merkez kayması (piksel)."""
    ir, rgb = _centers(coco_ir), _centers(coco_rgb)
    offsets: list[float] = []
    un_ir = un_rgb = 0
    for name in sorted(set(ir) | set(rgb)):
        a, b = ir.get(name, []), rgb.get(name, [])
        pairs = sorted(
            (d, i, j)
            for i, p in enumerate(a)
            for j, q in enumerate(b)
            if p[0] == q[0] and (d := math.dist(p[1:], q[1:])) <= max_dist
        )
        used_a: set[int] = set()
        used_b: set[int] = set()
        for d, i, j in pairs:
            if i not in used_a and j not in used_b:
                used_a.add(i)
                used_b.add(j)
                offsets.append(d)
        un_ir += len(a) - len(used_a)
        un_rgb += len(b) - len(used_b)
    return {"matched": len(offsets), "unmatched_ir": un_ir, "unmatched_rgb": un_rgb,
            "offsets": offsets}


def summarize(coco: dict) -> dict:
    names = {c["id"]: c["name"] for c in coco["categories"]}
    per_img = collections.Counter(a["image_id"] for a in coco["annotations"])
    per_cls = collections.Counter(names[a["category_id"]] for a in coco["annotations"])
    size = {"small": 0, "medium": 0, "large": 0}
    for a in coco["annotations"]:
        size["small" if a["area"] < 32**2 else "medium" if a["area"] < 96**2 else "large"] += 1
    return {
        "images": len(coco["images"]),
        "boxes": len(coco["annotations"]),
        "per_class": {n: per_cls.get(n, 0) for n in names.values()},
        "max_per_image": max(per_img.values(), default=0),
        "empty_images": len(coco["images"]) - len(per_img),
        "size": size,
    }

    out = ["| " + " | ".join(header) + " |", "|" + "---|" * len(header)]
    out += ["| " + " | ".join(str(c) for c in r) + " |" for r in rows]
    return "\n".join(out)

                         "maks kutu/görüntü (IR)", "boş görüntü"]), ""]
